两个角色，两套后端（关键区分）

场景在哪跑谁推理向量花钱
A · 你在 VS Code 问知识
本地 session		 你的 Mac 我（Claude 订阅） vectors.npz
e5/bge · 本地		 0 API 费
B · WhatsApp 自动问答
云端服务		 Railway gpt-4o-mini vectors-openai-384.npz
OpenAI 256 维		 每问几厘

为什么两套向量：云端不装 torch（省内存、防 OOM），只能用 OpenAI 算查询向量；本地免费用 e5。 两份并存、互不干扰——编辑器里问是免费的，WhatsApp 那条给「人不在也能自动答」用。
